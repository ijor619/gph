# Бот для автозаполнения договоров ГПХ и Согласий на обработку ПД с курьерами

Готовый к деплою на **Bothost** (или любой другой VPS/хостинг) Telegram-бот на `aiogram 3`.

---

## 📦 Файлы проекта

- `bot.py` — основной файл Telegram-бота (диалог, загрузка фото, кнопки проверки, генерация 2-х документов, таймер очистки 2 минуты).
- `contract_filler.py` — генератор `.docx` документов (Договор ГПХ + Согласие на обработку ПД) по шаблонам с сохранением шрифтов и стилей.
- `extractor.py` — модуль OCR / распознавания документов курьеров (Vision API).
- `template.docx` — исходный шаблон Word договора ГПХ.
- `template_pd.docx` — шаблон Word согласия на обработку ПД.
- `requirements.txt` — Python-зависимости.
- `.env.example` — пример конфигурации переменных окружения.
- `Dockerfile` / `Procfile` — файлы автозапуска для BotHost.

---

## ⚙️ Настройка на BotHost

1. Создайте нового бота на [Bothost](https://bothost.ru).
2. Подключите ваш Git-репозиторий (куда загрузите содержимое этой папки).
3. В панели Bothost в разделе **«Переменные окружения» (Environment Variables / .env)** добавьте:
   - `TELEGRAM_BOT_TOKEN` = ваш токен от `@BotFather`
   - `OPENAI_API_KEY` = ключ OpenAI (или ключ от шлюза ProxyAPI)
   - *(Опционально)* `OPENAI_BASE_URL` = если используется прокси (например, `https://api.proxyapi.ru/openai/v1`)
4. Команда запуска (если требуется указать вручную):
   ```bash
   python bot.py
   ```
5. Нажмите **Deploy** (или Запустить).

---

## 🔒 Безопасность и 152-ФЗ

- После отправки готового Договора ГПХ и Согласия на обработку ПД в чат бот запускает **таймер на 2 минуты** (`asyncio.create_task`).
- По истечении 2 минут папка сессии с исходными фотографиями паспортов, ВНЖ, ИНН, СНИЛС и сгенерированными файлами **безвозвратно удаляется с сервера**.
- Никакие персональные данные на сервере не сохраняются.
