# Бот для автозаполнения договоров ГПХ и Согласий на обработку ПД курьеров

Telegram-бот на **aiogram 3** для автоматизации кадрового документооборота курьеров (включая иностранных граждан: ВНЖ, патент, РВП, регистрация, ИНН, СНИЛС, банковские реквизиты).

---

## ⚡ Что делает бот:
1. **Принимает фото или файлы документов** (паспорт, ВНЖ / патент / РВП, регистрация, ИНН, СНИЛС, банковские реквизиты).
2. **Распознает все данные через Vision AI**:
   - Бесплатный **Google Gemini Flash** (вечный алиас `gemini-flash-latest` + динамическое автоопределение моделей).
   - Российский шлюз **ProxyAPI** (`proxyapi.ru`) с бесплатным стартовым балансом (рекомендуется для Bothost в РФ).
   - **OpenRouter** (`openrouter.ai`) с поддержкой бесплатных моделей.
3. **Рассчитывает даты по регламенту**:
   - Дата договора и согласия ПД: **текущая дата календаря + 1 день** (завтрашний день).
   - Срок действия: **ровно 6 месяцев** от даты подписания.
   - Строка подписи: Фамилия И.О. и дата подписания.
4. **Формирует 2 документа Word (`.docx`)**:
   - Договор ГПХ с курьером (`template.docx`).
   - Согласие на обработку персональных данных (`template_pd.docx`).
5. **Безопасность (152-ФЗ)**:
   - Ровно через **3 минуты** все фото документов, сгенерированные файлы Word и сообщения удаляются из чата Telegram и стираются с диска сервера.

---

## 📦 Файлы проекта

- `bot.py` — основной файл бота (прием фото/файлов в любом состоянии, автоудаление через 3 мин, интерактивная карточка проверки).
- `extractor.py` — извлечение данных через Vision API (динамический опрос моделей Gemini, защита от 404, fallback на OpenAI/ProxyAPI).
- `contract_filler.py` — генератор `.docx` документов по шаблонам.
- `template.docx` — шаблон договора ГПХ.
- `template_pd.docx` — шаблон согласия на обработку ПД.
- `requirements.txt` — зависимости Python.
- `.env.example` — образец переменных.
- `Dockerfile` / `Procfile` — конфигурация запуска на Bothost.

## ⚙️ Установка на Bothost

1. Скопируйте файлы в ваш репозиторий GitHub: `https://github.com/ijor619/gph.git`.
2. В панели управления Bothost перейдите в **«Переменные окружения» (Environment)** и укажите:
   - `TELEGRAM_BOT_TOKEN` = токен вашего бота от `@BotFather`
   - `GEMINI_API_KEY` = бесплатный ключ с [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
     *(Если Google блокирует запросы из-за IP РФ, укажите `OPENAI_API_KEY` и `OPENAI_BASE_URL=https://api.proxyapi.ru/openai/v1` от сервиса ProxyAPI).*
3. Перезапустите бота.
